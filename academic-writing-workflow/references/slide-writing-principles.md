# Slide Writing Principles

Use these rules when writing, editing, restructuring, or reviewing academic economics slides.

## Core Slide Argument

- Build slides around the economics question, not the paper outline.
- Use newspaper structure: main point first, main steps second, details last.
- Start with the idea, thesis, or research question rather than background throat-clearing.
- State the contribution before technical detail.
- Present evidence in the order needed for the audience to believe the answer.
- Separate what the paper shows from why it matters.
- Use transitions, previews, and recalls so the audience knows where the talk is coming from and where it is going.

## Frame-Level Editing

- Make each slide carry one idea.
- Use takeaway titles that state the slide's claim, not labels such as "Results" or "Model".
- Use short, direct frame titles; prefer noun-phrase or result titles over full-sentence titles.
- Put only the bare essentials on main slides.
- Keep bullets short and one-line where possible.
- Minimize explanatory text around tables and figures; keep only the visual and a precise note when needed.
- Put oral-delivery guidance in concise LaTeX comments, not visible bullets.
- Use bold section labels inside slides to organize logic.
- Use color consistently and semantically, not decoratively.
- Move rigor-only details, robustness, derivations, long tables, and secondary qualifications to backup slides.

## Figures, Tables, And Equations

- Prefer figures, diagrams, and result-focused visuals over dense text or full regression tables.
- Use figures for patterns, contrasts, trends, mechanisms, and model intuition.
- Label axes, curves, units, and comparison groups clearly.
- Use figure fonts that are much larger than paper-figure fonts.
- Keep figures visually simple; use at most about three plotted series unless there is a strong reason.
- Use tables only when exact numbers matter, and show only the rows and columns that will be discussed.
- If a table needs more than roughly ten numbers, turn it into a figure or split it.
- Use equations sparingly and define notation where the audience needs it.

## Language And Consistency

- Use the same term for the same object throughout the talk.
- Avoid elegant variation: do not switch between terms such as "firm", "company", "producer", and "decision maker" unless the distinction matters.
- Use established concepts, conventions, and notation where possible.
- Prefer active verbs, parallel structure, and short direct phrasing.
- Cut formal filler and use the shortest clear wording.

## Editing Output

- Preserve the user's claims, notation, empirical qualifications, and hedge strength.
- Preserve Beamer commands and frame structure unless changing them is part of the request.
- For selected slide text, return revised slide text and a short note on the editing logic.
- For direct file edits, change only the requested frames unless a neighbouring transition must be adjusted.
